# Normalization Concepts

## What is normalization?

Normalization transforms plugin formats to a standard structure. This ensures consistency across all plugins.

## Key principles

1. All paths are relative to plugin root
2. All optional fields have default values
3. Schema validation is enforced

## Benefits

- Predictable structure
- Easier to validate
- Consistent behavior
