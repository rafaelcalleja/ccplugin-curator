# mkcurator

TUI application for curating Claude Code plugin components.

## Installation

```bash
npm install
npm run build
```

## Usage

```bash
mkcurator select <plugin-folder>
```

## Development

```bash
npm run dev          # Watch mode
npm run generate-types  # Generate TypeScript types from schemas
```

## Features

- Scan and discover Claude Code plugins
- Interactive TUI for component selection
- Real-time JSON preview
- Save curated plugin configurations
